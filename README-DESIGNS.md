# 5 Unique Card Shop Designs

## 🎯 Design Overview

### 1️⃣ **MINIMALIST MODERN** (01-minimalist-cards.jsx)
- **Style:** Notion/Linear inspired, clean and spacious
- **Colors:** Black, white, gray
- **Typography:** Light, elegant
- **Features:** Simple grid, subtle interactions, focus on content
- **Best for:** Luxury, premium feel, professional buyers
- **Key Elements:** Light fonts, whitespace, minimal borders

---

### 2️⃣ **BOLD GRADIENT** (02-bold-gradient-cards.jsx)
- **Style:** Dribbble-inspired, vibrant and playful
- **Colors:** Purple, pink, cyan, orange, yellow gradients
- **Typography:** Heavy black fonts, eye-catching
- **Features:** Large cards with gradients, hover animations, vault theme
- **Best for:** Young audience, gaming community, trendy look
- **Key Elements:** Gradient backgrounds, scale animations, bold text

---

### 3️⃣ **GLASSMORPHISM** (03-glassmorphism-cards.jsx)
- **Style:** Frosted glass, modern and elegant
- **Colors:** Soft pastels with transparency
- **Typography:** Medium weight, readable
- **Features:** Backdrop blur, animated blobs, soft shadows
- **Best for:** Contemporary, sophisticated, creative crowd
- **Key Elements:** Backdrop-blur, border-white/40, animated gradient blobs

---

### 4️⃣ **DARK BRUTALISM** (04-brutalism-cards.jsx)
- **Style:** Raw, industrial, stark contrast
- **Colors:** Black and white only
- **Typography:** Heavy monospace, uppercase
- **Features:** Thick borders, bold lines, classified theme
- **Best for:** Tech-savvy, industrial aesthetic, bold statement
- **Key Elements:** 4px borders, monospace fonts, uppercase text, stark contrast

---

### 5️⃣ **AI/FUTURE TECH** (05-ai-future-cards.jsx)
- **Style:** Futuristic, data-heavy, interactive
- **Colors:** Cyan, blue, green, black
- **Typography:** Monospace, tech-like
- **Features:** Live animations, neural network theme, market data display
- **Best for:** Tech enthusiasts, gamers, innovation-focused
- **Key Elements:** Animated grid, live price updates, carousel rotation, data visualization

## 🚀 How to Use

Each design is a standalone React component. To use:

1. Copy the `.jsx` file to your Next.js project
2. Import and use: `import CardStore from './01-minimalist-cards'`
3. Install dependencies: `npm install lucide-react`

## 🎨 Customization Tips

### Minimalist
- Change `bg-white` to `bg-gray-50` for warmer feel
- Increase border radius for softer look

### Bold Gradient
- Swap colors in gradient classes
- Change Zap icon to other icons from lucide-react
- Adjust shadow opacity for more/less depth

### Glassmorphism
- Increase `blur-md` to `blur-xl` for more effect
- Change blob colors to match brand
- Adjust opacity of `/30` to `/20` or `/40`

### Brutalism
- Remove borders for softer version
- Change monospace font to regular
- Add colors to black/white palette

### AI Future
- Speed up carousel with smaller interval
- Change cyan to your brand color
- Add real data endpoints for prices
